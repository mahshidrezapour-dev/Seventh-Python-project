# Expense Tracker

A simple expense management system built with Python. This project allows users to record expenses, organize them by category, and track their spending through a command-line interface.

## Features

- Add expenses with a title, amount, and category.
- Display all recorded expenses in a readable format.
- Search for expenses by title.
- Calculate total expenses.
- Calculate total spending for a specific category.
- Delete expenses and update the total amount.
- Prevent duplicate expense titles.
- Validate expense amounts using Python's `Decimal` module.
- Reject negative and non-finite amounts.
- Prevent empty expense titles.

## Technologies

- Python 3
- Decimal
- Dictionaries
- Functions
- Loops and conditional statements
- Exception handling
